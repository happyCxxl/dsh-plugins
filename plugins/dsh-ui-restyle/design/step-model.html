四条原则：成功故意变暗（常态不抢眼）；强调色只给运行中；列对齐（等宽 tabular）；信息就地（错误写行内）。

状态组头表现 / 步骤行表现
○queued 组头：不体现（排队不打扰）。步骤行：空心微环 · 最暗 · 耗时位 — 占位保证列对齐
⠹running 组头：呼吸转轮 + 计数/耗时转强调色 + 当前步骤在组成串里点亮 + 计时每秒跳。步骤行：转轮 + 实时计时
✓ok 组头：细勾 · 三级文字色（安静）。步骤行：细勾 · 三级色 · 耗时右对齐。成功不配强调色
✕error 组头：红叉 + N 失败 红字 + 整行提亮到二级色。步骤行：红叉 + 行内第二行写错误摘要
–stopped 组头：琥珀短横 + 「已中止」。步骤行：琥珀 · 目标加删除线 · 耗时位写「已中止」
└nested 组头：并入父步骤，不单独计数。步骤行：缩进 24px + 发丝折线 + 再暗一档
