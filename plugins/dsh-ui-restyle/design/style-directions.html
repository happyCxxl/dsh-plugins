dsh-ui-restyle · 四个专业设计方向

全部取自 DSH 自身设计系统（字体栈 / 颜色 token / 字号尺度 / 动效曲线），目标是"像原生长出来的"，而不是贴上去的皮肤。

四版内容完全一致：用户消息 · 正文（含列表、行内代码、代码块）· 已完成摘要 · 运行中摘要 · 展开的工作行。

01RestrainedLinear 设计语言

核心：把工作行做成一条被 上下 0.5px 发丝线夹住的微型大写行——无节点、无圆点、无填充、无圆角。计数用等宽 tabular-nums 对齐，耗时右对齐。 强调色只出现一次（运行中那一行）。正文保持 14/24 与最高对比度，是最"安静"的一版。

帮我看下这个报错，为什么 dsh web 起不来？
这个报错是依赖版本冲突导致的。profile 里装的是 @cxxl/dsh-sqlite@0.3.0，而它缺了 lib/coordination.js——index.js 里 import 了它，加载时直接 ERR_MODULE_NOT_FOUND。
已经定位到根因，正在修复。
pwshnpm publish --access publicok

02LayeredRaycast 设计语言

核心：聊天区做成一块比应用更暗的"下沉画布"（#0b0b0e）+ 内嵌顶部高光；摘要行是一条浅底信息条卡片（圆角 9、1px 边、圆点状态、等宽摘要、右对齐耗时）。 正文降一档对比度，让信息条浮起来。最有"贵"感和层次感的一版。

03BlocksWarp 终端 block 模型

核心：把每个折叠段做成一个带边框的圆角"块"，块头就是摘要（箭头 + 标签 + 等宽计数 + 右对齐耗时 + 方形状态点），块体可展开。 多块之间 6px 间距，形成一条可见的工作时间线。正文留在块外——正文与工作形成清晰的图层分离。

04MarginStripe Docs / 技术长文排版

核心：双栏栅格——左栏一条贯通全回合的发丝线 + 微型方形节点，右栏是正文。正文放大到 15.5px / 1.82、限宽 64ch（长时间阅读最舒服）。 工作行压成等宽大写微型批注贴在轨道上，耗时右对齐。最"阅读优先"、最有书卷气的一版。
