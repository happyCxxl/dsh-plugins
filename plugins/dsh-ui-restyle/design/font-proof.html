  • Segoe UI 是静态字体，没有 510 这一档 —— 而「字重 510」正是 Linear 全部质感的命门；Inter Variable 有 100–900 连续字重。
  • Inter 全局开启 cv01 / ss03 OpenType 特性，字形更几何、更"工具感"；Segoe UI 没有。
  • Consolas 是 2006 年的老字体；JetBrains Mono 的字腔、连字、tabular-nums 对齐是现代代码字体的水准。
  • 正字距（+0.01em）在深色底上"透气"，负字距（-0.011em）让大字不松散 —— 这些微调只有在可变字体上才能做。
01PrecisionLinear 手法

发丝线（0.5px 上下夹）+ 微小正字距（+0.01em）+ 字重 510 + 等宽计数 tabular-nums + 耗时右对齐。 半径 ≤8px、无节点无填充、强调色全场只出现一次。正文 15px/25、-0.011em（Linear 的段落处理），限宽 66ch。

02AiryRaycast 手法

正文也用 500 字重（Raycast：深色底上"重一点"更易读）+ 正字距 +0.012em + 下沉画布 + 内嵌顶部高光（inset 0 1px 0 rgba(255,255,255,.05)）。 摘要行是浅底信息条卡片，hover 用 opacity 而非换底色（Raycast 的标志性交互）。最"透气"、最有产品感。

03Quiet融合（推荐）

保留 DSH 原生表面与 token（所以和侧栏、输入区天然和谐），但把字重纪律（510/590）、逐级字距、等宽 tabular 计数、半径 ≤8 全部补齐。 摘要行是贴着发丝轨道的极简行——有节点但没填充，hover 只微微提亮。最"不像外挂"的一版。
