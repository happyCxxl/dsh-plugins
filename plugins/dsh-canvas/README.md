## 一句话定位

**把自然语言需求生成为精美的、动态可交互的单页 HTML 产物；支持对话修改、可视化编辑与 git 版本化。**

产出是**工作区 `canvas/<产物名>/` 下的真实 HTML 文件**，agent 可以直接编写与修改它；产物**自包含、离线可用**，并带**真正生效的交互**。
