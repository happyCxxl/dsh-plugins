# v2 文档索引

## 这个目录是什么

**本目录描述本插件的重构后路线（v2）。** 它取代 `docs/` 根下的旧设计。

**隔离约定**（本目录的文档遵守以下三条）：

1. **物理隔离**：v2 的全部内容只在本目录下，**不修改 `docs/` 根下的任何旧文档**
2. **顺序即依赖**：文档以 `NN-` 编号，按讨论顺序落盘；后面的文档可以引用前面的，反之不行
3. **只写"应该是什么"**：v2 文档描述**目标状态**，不描述当前实现。实现细节在议题讨论到之前不写

### 研究方法约定（由议题 2 的两次失误得出）

**遇到设计问题，先查参考方案（deepseek-idesign）怎么解，再结合实测判断是否照抄、何处增强。**

反例（议题 2 中真实发生两次）：

- 实测出"`srcdoc` 不能加载外链"就断言"必须用真实 URL"——**实际参考方案用 `srcdoc` + 内联依赖，早已解决**
- 判断"产物路由不能做 token 认证"——**实际参考方案的同一路由被 `fetch` 带 header 访问，认证正常**

**两次都是"先自己下结论、后去查参考"，于是参考信息只能用来补注，不能用来形成结论。** 详见 [`00-重构决策记录.md`](00-重构决策记录.md) 附二。



### 议题 1 已冻结的关键结论

| 结论 | 位置 |

| agent 直接编写与修改 HTML 是产出的根本方式 | `01` §3.1 |

| **"精美"是审美决定，不是规范问题** | `00` §4、`01` §7.1 |
